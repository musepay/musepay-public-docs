# 简介

MusePay 提供 API 基础设施，帮助您将数字货币支付、发卡、资产管理、兑换和法币出款能力嵌入自己的产品。统一的 API 模型让您的系统能够便捷地使用这些能力，底层支付和金融操作则由 MusePay 负责处理。

## MusePay 的工作方式

MusePay 集成由以下三个部分组成：

* **APIs** 用于从您的后端发起操作和查询信息。
* **Partner Portal** 用于执行 API 访问管理、账户入金和配置等运营操作。
* **Webhooks** 用于向您的系统通知异步订单和卡片事件。
