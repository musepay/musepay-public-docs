# Card API

The MusePay Card API lets partners build a complete card experience into their products. Create and manage cardholders, issue cards, manage card status and settings, fund card accounts, and respond to transaction verification requests.

## API reference

Use these endpoint references while implementing the workflows:

* [Card User](../../reference/api-reference/card-api/card-user.md) — create cardholders and manage identity and KYC information.
* [Card](../../reference/api-reference/card-api/card.md) — issue, retrieve, activate, lock, update, or replace cards and respond to verification requests.
* [Card Account](../../reference/api-reference/card-api/card-account.md) — top up cards and query card account transactions.
