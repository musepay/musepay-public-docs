# Payout Quotations

{% hint style="warning" %}
Every request must contain [common parameters](../common-parameters.md).
{% endhint %}

## Create Payout Quote

Creates a quote for converting USDT into the fiat currency received by the beneficiary.

<mark style="color:green;">`POST`</mark> `/v1/fiatpayout/quotations/create`

### Request Body

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| enterNo | String | Yes | Enterprise number issued to the organization. |
| custQuoteNo | String | Yes | Unique quote identifier supplied by the organization. Used as the idempotency key. |
| quoteMode | String | Yes | Quote mode. Use `source` to specify `payAmount`, or `dest` to specify `recvAmount`. |
| payCcy | String | Yes | Source asset code. Use `USDT` for a payout funded from the USDT balance. |
| payAmount | Number | Conditional | Amount deducted from the USDT balance. Required when `quoteMode` is `source`. |
| country | String | Yes | Beneficiary country or region as an ISO 3166-1 alpha-2 code. |
| recvCcy | String | Yes | Fiat currency received by the beneficiary, as an ISO 4217 currency code. |
| recvAmount | Number | Conditional | Fiat amount received by the beneficiary. Required when `quoteMode` is `dest`. |
| localQuote | Object | Conditional | Local payout configuration. Provide either `localQuote` or `internationalQuote`. |
| localQuote.payerBankId | String | Yes | Identifier of the beneficiary bank. Required when `localQuote` is provided. |
| internationalQuote | Object | Conditional | International wire configuration. Provide either `internationalQuote` or `localQuote`. |
| internationalQuote.accType | String | Yes | Beneficiary account type: `01` for an individual or `03` for an organization. |
| internationalQuote.supportSame | String | Yes | Beneficiary relationship: `own` for the organization's own account or `third` for a third-party account. |
| internationalQuote.bankFeeType | String | Yes | Bank fee allocation: `SHA`, `OUR`, or `BEN`. |

### Request Example

```json
{
  "enterNo": "E202605050001",
  "custQuoteNo": "CUST-QT-001",
  "quoteMode": "source",
  "payCcy": "USDT",
  "payAmount": 1000.00,
  "country": "US",
  "recvCcy": "USD",
  "localQuote": {
    "payerBankId": "3635"
  }
}
```

### Response Body

| Name | Type | Description |
| --- | --- | --- |
| custQuoteNo | String | Quote identifier supplied by the organization. |
| quoteNo | String | Quote identifier generated by MusePay. |
| transTime | Number | Time at which the quote was created, as a 13-digit Unix timestamp in milliseconds. |
| quoteMode | String | Quote mode used for the request. |
| payAmount | Number | Amount deducted from the source balance. |
| payCcy | String | Source asset code. |
| fee | Number | Payout fee. |
| transFeeCcy | String | Currency in which the fee is charged. |
| rate | Number | Exchange rate from `payCcy` to `recvCcy`. |
| recvAmount | Number | Fiat amount received by the beneficiary. |
| recvCcy | String | Beneficiary currency. |
| expireTime | Number | Quote expiration time, as a 13-digit Unix timestamp in milliseconds. |

```json
{
  "code": "200",
  "message": "success",
  "data": {
    "custQuoteNo": "CUST-QT-001",
    "quoteNo": "QT202605050001",
    "transTime": 1777946400000,
    "quoteMode": "source",
    "payAmount": 1000.00,
    "payCcy": "USDT",
    "fee": 5.00,
    "transFeeCcy": "USDT",
    "rate": 1.0000,
    "recvAmount": 995.00,
    "recvCcy": "USD",
    "expireTime": 1777946700000
  }
}
```

## Query Payout Quote

Retrieves a payout quote by its MusePay quote number or the organization's quote identifier.

<mark style="color:green;">`POST`</mark> `/v1/fiatpayout/quotations/query`

### Request Body

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| enterNo | String | Yes | Enterprise number issued to the organization. |
| quoteNo | String | Conditional | Quote identifier generated by MusePay. Provide either `quoteNo` or `custQuoteNo`. |
| custQuoteNo | String | Conditional | Quote identifier supplied by the organization. Provide either `custQuoteNo` or `quoteNo`. |

### Request Example

```json
{
  "enterNo": "E202605050001",
  "quoteNo": "QT202605050001"
}
```

The response uses the same `data` object documented under [Create Payout Quote](#create-payout-quote).
